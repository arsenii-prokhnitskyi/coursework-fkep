# UnApp — аналітика та планування проєктів

Мій курсовий проєкт із дисципліни «Мови програмування для Web».
Я реалізував українськомовний сайт за макетом UnApp: головну сторінку,
блог і послуги. Контент присвячений завданням, строкам, бюджету та роботі команди.

## Технології

HTML5, CSS3, Flexbox, Grid, Vanilla JavaScript, WebP та SVG.
Сайт статичний: серверного застосунку, API, бази даних і залежностей для встановлення немає.

## Структура

- `index.html` — головна сторінка.
- `blog.html` — дев’ять коротких матеріалів про планування проєктів.
- `services.html` — опис послуг і ролей команди.
- `404.html` — сторінка помилки.
- `assets/css/style.css` — спільні стилі.
- `assets/js/main.js` — меню, модальна форма, валідація та кнопка «Вгору».
- `assets/images/` — зображення, favicon, CSS Sprite та SVG Sprite.
- `.nojekyll` — вимкнення оброблення Jekyll на GitHub Pages.

## Функціональність

- Адаптивні сторінки для комп’ютерів, планшетів і телефонів.
- Мобільне меню й переходи між сторінками та секціями.
- Модальна форма з перевіркою імені, пошти й опису потреб.
- Закриття форми кнопкою, натисканням на фон або Escape.
- Керування фокусом і навігація клавішею Tab у модальному вікні.
- Кнопка повернення нагору, пояснення приватності, заглушка для недоступних зображень.

Обидві форми демонстраційні. Перевірка відбувається у браузері:
заявки не надсилаються, дані не зберігаються, підписка на розсилку не оформлюється.
Панелі показників, тарифи та команда — навчальні приклади.
Номери додаткових сторінок у пагінації неактивні.

## Локальний перегляд

Відкрити папку у VS Code і запустити `index.html` через Live Server.
Статичний HTTP-сервер потрібний для коректного завантаження зовнішнього SVG-спрайта.
Збирання проєкту й установлення пакетів не потрібні.

## Публікація на GitHub Pages

Репозиторій: https://github.com/arsenii-prokhnitskyi/coursework-fkep

1. Завантажити вміст цієї папки в корінь репозиторію. `index.html` має бути в корені.
2. Відкрити **Settings → Pages**.
3. У **Source** вибрати **Deploy from a branch**.
4. Вибрати гілку **main**, папку **/(root)** і натиснути **Save**.
5. Після завершення публікації відкрити **Visit site**.

Адреса після ввімкнення Pages: https://arsenii-prokhnitskyi.github.io/coursework-fkep/

У `404.html` базовий шлях налаштовано для репозиторію `coursework-fkep`,
щоб оформлення і кнопка повернення працювали також для вкладених невідомих адрес.
